ED Graph Studio (offline, single HTML file)

1. Extract this ZIP archive.
2. Open index.html with Chrome or Microsoft Edge (double-click file).
3. Select experiment and feed solution.
4. Enter the questions for each measured point; click Add Measurement.
5. Select a graph; click Plot Graph.
6. Click Download PNG. If it is blocked, click Open PNG in new tab and right-click the graph > Save image as.

To edit in VS Code: File > Open Folder > ED_Graph_Studio_Fixed_Project and edit index.html.
This version requires no Python, extensions, internet access or external JavaScript libraries.
Measurement data exist only while the page remains open. Export CSV for records.
